# Species Video Clips

Short 3-4 second looping video clips for the top 30 most commonly owned aquarium fish.

## File Naming Convention
Files should be named using the scientific name in lowercase, with spaces replaced by hyphens.
Format: `{scientific-name}.mp4`

## Video Specs
- Duration: 3-4 seconds
- Resolution: 480x360 (or 16:9 aspect ratio)
- Format: .mp4 (H.264) for broad browser support
- Loop-friendly: start and end frames should blend smoothly
- Subtle motion: gentle swimming, fin movement, slight drift
